# TESMUN XIV

Official conference website for The Excelsior School Model United Nations, session XIV.

## Stack

Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion

## Structure

```
src/
  App.tsx
  main.tsx
  index.css
  components/
  lib/
  pages/
public/images/
```

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
